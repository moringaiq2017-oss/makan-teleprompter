# Makan Prompter

Teleprompter Web App for Meta Ray-Ban Display glasses (Makan Studios).

- App: https://moringaiq2017-oss.github.io/makan-teleprompter/
- Install QR (scan with the glasses): https://moringaiq2017-oss.github.io/makan-teleprompter/install.html

## Scripts
- Shared scripts: edit `scripts.json` and push — GitHub Pages redeploys automatically.
- On the glasses: "+ نص جديد" opens the system composer (dictation/handwriting); saved locally on the glasses.

## Controls (touchpad / Neural Band)
Arrows move focus, Enter activates: `−` / `+` speed, `▶` play/pause, `A−` / `A+` text size, `⟲` restart. Back returns to the list.

Plain static files, no build step.
